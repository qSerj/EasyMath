# Визуальные договорённости

**Источник:** `01-original-by-parent.svg` — исправленный пользователем рисунок; использовать его в качестве ориентира, а не заново переизобретать стиль.

- Формат листа: А4, векторный Inkscape SVG.
- Математика — контрастно и читабельно; пояснения — сдержанным цветом.
- Одна горизонтальная цепочка обычного вычислительного примера; очень маленькая цифра прямо над каждым знаком равенства.
- Вертикальная цепочка строк уравнения; равенства совпадают по X; цифры строк одинаковы по размеру, совпадают по X.
- У подписей должны быть ясные визуальные объекты, к которым они относятся; центрировать относительно объекта.
- Не вводить случайные размеры шрифтов/цвета: взять небольшую типографическую палитру из оригинала, при необходимости нормализовать.
- Тонкие стрелки, обводки и пунктир служат смыслу, а не украшению.
- Важный текст можно сделать на 1–2 пункта крупнее; определения и терминология должны появляться только там, где объясняются.
- Не использовать масштабирование (`transform:scale(...)`) для выравнивания отдельных цифр; задавать одинаковый `font-size`, `x`, `y`, `text-anchor` явно.
- В многострочных SVG-текстах допустимы `<tspan>`, каждая строка остаётся редактируемой. При вставке новой строки **проверять расстояние до следующего заголовка**.
- Экспорт PDF: проверка полей, читаемости при печати на A4, отсутствия наложений и переполнения за край.
