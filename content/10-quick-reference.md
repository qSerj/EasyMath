# Короткая справка

Назначение: один А4 после разбора, перед глазами во время решения. Правила и короткие примеры, без повторного объяснения. Умножение, деление и вложенные скобки не вводим.

Сначала раскрываем скобки. Затем упрощаем и решаем.

## Скобки

Перед скобками плюс — знаки внутри сохраняем. Перед скобками минус — каждый знак внутри меняем.

`x + (4 − 2)` → `x + 4 − 2`

`x − (4 − 2)` → `x − 4 + 2`

## Пары внутри одной части

Одинаковые числа с разными знаками дают ноль. Убираем пару вместе со знаками.

`x + 7 + 4 − 7` → `x + 4`

## Одинаковые числа с обеих сторон

Одинаковые числа с одинаковыми знаками убираем одновременно из обеих частей.

`x + 12 = 3 + 12` → `x = 3`

`x − 4 = 9 − 4` → `x = 9`

## Одинаковое действие

Прибавляем или вычитаем одно и то же одновременно в обеих частях. Это может быть и x.

`8 − x = 3`

`8 − x + x = 3 + x`

`8 = 3 + x`

## Перенос через знак равенства

Переносим число через «=» — меняем его знак.

`x + 3 = 8` → `x = 8 − 3`

`x − 2 = 6` → `x = 6 + 2`

## Перестановка внутри одной части

В левой или правой части переставляем число вместе с его знаком.

`x + 8 − 3 + 2` → `x + 8 + 2 − 3`

Перед первым положительным числом плюс обычно не пишут.

## Обмен частей

Меняем левую и правую части местами целиком. Знаки сохраняем.

`8 = x + 3` → `x + 3 = 8`

## Проверка

Подставляем найденное число вместо x в исходное уравнение. Обе части должны быть равны.

`x + 3 = 8`, ответ `x = 5`.

`5 + 3 = 8` → `8 = 8`

## Вёрстка

Восемь небольших блоков на одном А4. При преобразовании одной части — стрелка. Уравнения — отдельными строками. Зачёркивания наклонные; рамки и стрелки приглушённые. Красный — одновременность действия с обеих сторон. Фрагменты, участвующие в действии, выделены рамками и цветом.
