# Листок для ребёнка — ПРОЕКТ

**Статус: ЧЕРНОВИК.** Включать только правила, уже объяснённые ребёнку. Один лист А4, минимум текста.

## Запомни

**Решить уравнение — найти число, которое спрятано за x.**

В записи `x − 3 + 2` слагаемые — это `x`, `−3` и `+2`.

**Внутри одной части:** переставляй слагаемые вместе с их знаками.

`x − 3 + 2 = x + 2 − 3`

**Через знак равенства:** переносишь слагаемое — меняешь знак.

```text
x + 3 = 8
x = 8 − 3
x = 5
```

```text
x − 2 = 6
x = 6 + 2
x = 8
```

**К обеим частям можно прибавить одно и то же число.**

**Из обеих частей можно вычесть одно и то же число.**

`x + 3 − 3 = 8 − 3`

**Можно поменять обе части местами.**

`45 = x` → `x = 45`

**Скобки с `+` — знаки сохраняются. Скобки с `−` — знаки меняются.**

Если перед первым числом внутри скобок знак не написан, это `+`. Его тоже учитываем.

`x + (4 − 2) = x + 4 − 2`

`x − (4 − 2) = x − 4 + 2`

**Когда получили `x = число`, уравнение решено.**

*Внимание: этот листок не содержит уравнений, требующих деления обеих частей, например `3x = 12`.*
