# Правила перед глазами

## 1. Внутри одной части уравнения

**Переставляем числа вместе с их знаками.**

`x − 3 + 5` → `x + 5 − 3`

`x − 3 + 5` → `5 + x − 3`

`x − 3 + 5` → `−3 + x + 5`

## 2. Одинаковое действие с обеими частями

**К обеим частям можно прибавить одно и то же число.**

**Из обеих частей можно вычесть одно и то же число.**

```text
x − 2 = 6
x − 2 + 2 = 6 + 2
```

```text
x + 3 = 8
x + 3 − 3 = 8 − 3
```

## 3. Перенос через знак равенства

**Переносим число в другую часть — меняем его знак.**

`x + 3 = 8` → `x = 8 − 3`

`x − 2 = 6` → `x = 6 + 2`

## 4. Обмен частей

**Меняем части местами целиком. Знаки внутри сохраняются.**

`8 = x + 3` → `x + 3 = 8`

## 5. Раскрытие скобок

**Перед скобками плюс — знаки внутри сохраняем.**

**Перед скобками минус — каждый знак внутри меняем.**

`x + (4 − 2)` → `x + 4 − 2`

`x − (+4 − 2)` → `x − 4 + 2`

## 6. Проверка

**Подставляем ответ вместо x в исходное уравнение.**

**Значения обеих частей должны совпасть.**

`x + 3 = 8; x = 5` → `5 + 3 = 8` → `8 = 8`

## Указания для макета

- В перестановке выделять `−3`, `+5`/`5` до и после перемещения. Весь пример относится к одной части уравнения.
- При одинаковом действии выделять оба добавленных `+2` или оба `−3`.
- При переносе выделять `+3` и `−3`, затем `−2` и `+2`.
- При обмене рамки охватывают части целиком.
- В скобках выделять знаки до и после раскрытия. Первый плюс во втором примере написан явно, чтобы было видно его изменение.
- При проверке одинаково выделять исходный `x` и подставленное вместо него `5`.
- Область применения: сложение и вычитание; памятка не содержит правил умножения и деления обеих частей. Эта редакторская ремарка в печатный лист не входит.
