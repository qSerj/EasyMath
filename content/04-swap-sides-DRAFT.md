# Блок 4. Меняем левую и правую части местами

**Статус: ЧЕРНОВИК.**

## Правило

**Левую и правую части уравнения можно поменять местами.**

`45 = x` → `x = 45`

`8 = x + 3` → `x + 3 = 8`

**Графика:** поменять местами целые пунктирные области «левая часть» / «правая часть», не трогая знаки внутри них. Это не перенос числа через `=`; знак у числа здесь **не меняется**.
