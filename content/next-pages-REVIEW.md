## Страница 2. Для родителей

# Как преобразуют уравнения

Здесь разбираем уравнения, которые решают с помощью сложения и вычитания.

### Переставляем слагаемые внутри одной части

В записи `x − 3 + 2` слагаемые — это `x`, `−3` и `+2`.

**Переставляем слагаемые внутри одной части — каждое вместе со своим знаком.**

Слагаемое с `+` переставляем вместе с плюсом. Слагаемое с `−` — вместе с минусом. У первого положительного слагаемого знак `+` обычно не пишут.

`8 + 5 − 3 = 8 − 3 + 5`

`x − 3 + 2 = x + 2 − 3`

В уравнении можно переставить слагаемые в левой или в правой части:

`x + 4 − 2 = 9` → `x − 2 + 4 = 9`

### Прибавляем и вычитаем одно и то же число

**К обеим частям уравнения можно прибавить одно и то же число.**

**Из обеих частей уравнения можно вычесть одно и то же число.**

Так правильный ответ уравнения не изменится.

Прибавим `2` к обеим частям:

```text
x − 2 = 6
x − 2 + 2 = 6 + 2
x = 8
```

Вычтем `3` из обеих частей:

```text
x + 3 = 8
x + 3 − 3 = 8 − 3
x = 5
```

### Переносим слагаемое через знак равенства

**Переносим слагаемое через знак `=` — меняем его знак.**

Здесь переносим числовые слагаемые: `−2` или `+3`. Такой перенос — короткая запись прибавления или вычитания одного и того же числа в обеих частях.

```text
x − 2 = 6
x = 6 + 2
x = 8
```

```text
x + 3 = 8
x = 8 − 3
x = 5
```

### Меняем части местами

**Левую и правую части уравнения можно поменять местами.**

`45 = x` → `x = 45`

`8 = x + 3` → `x + 3 = 8`

Меняем местами части целиком. Знаки внутри них сохраняются.

### Раскрываем скобки

**Перед скобками `+` — убираем скобки, знаки внутри оставляем.**

`x + (4 − 2) = x + 4 − 2`

`9 + (5 − 3) = 9 + 5 − 3`

**Перед скобками `−` — убираем скобки, каждый знак внутри меняем.**

Если перед первым числом внутри скобок знак не написан, это `+`. При раскрытии скобок он тоже меняется на `−`.

`x − (4 − 2) = x − 4 + 2`

`9 − (5 − 3) = 9 − 5 + 3`

## Страница 3. Для ребёнка

# Как решать уравнения

Решить уравнение — значит выяснить, какое число спрятано за x. Это число называется корнем уравнения.

### Внутри одной части

В записи `x − 3 + 2` слагаемые — это `x`, `−3` и `+2`.

**Переставляй слагаемые вместе с их знаками.**

`x − 3 + 2 = x + 2 − 3`

### Одно и то же действие с обеими частями

**К обеим частям можно прибавить одно и то же число.**

```text
x − 2 = 6
x − 2 + 2 = 6 + 2
x = 8
```

**Из обеих частей можно вычесть одно и то же число.**

```text
x + 3 = 8
x + 3 − 3 = 8 − 3
x = 5
```

### Через знак равенства

**Переносишь слагаемое — меняешь знак.**

Это короткая запись действия с обеими частями.

```text
x − 2 = 6
x = 6 + 2
x = 8
```

```text
x + 3 = 8
x = 8 − 3
x = 5
```

### Меняем части местами

**Можно поменять левую и правую части целиком.**

`45 = x` → `x = 45`

Знаки внутри частей сохраняются.

### Раскрываем скобки

**Перед скобками `+` — знаки внутри сохраняются.**

`x + (4 − 2) = x + 4 − 2`

**Перед скобками `−` — каждый знак внутри меняется.**

Если перед первым числом внутри скобок знак не написан, это `+`. Его тоже учитываем.

`x − (4 − 2) = x − 4 + 2`

### Проверяем ответ

**Подставь найденное число вместо x в исходное уравнение. Посчитай обе части. Должны получиться одинаковые числа.**

```text
x + 3 = 8
x = 5
5 + 3 = 8
8 = 8
```
