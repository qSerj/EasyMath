# Памятка по простым уравнениям — проект для Codex

**Задача:** подготовить к публикации в группе родителей аккуратный PDF: 1–2 листа А4 с объяснениями для родителей и один лист А4 для ребёнка. Не учебник; краткие процедуры, простые числа, наглядные преобразования.

## С чего начать

1. Прочитать `AGENTS.md`.
2. Использовать `design/01-original-by-parent.svg` **как главный визуальный образец**. Это авторский вариант первого блока, а не поздняя неудачная правка ассистента.
3. Текст первого блока находится в `content/01-intro-APPROVED.md`. В нём **уже записана** окончательно согласованная фраза о корне уравнения. В приложенном оригинальном SVG она ещё не обновлена.
4. Блоки `02–05` и детская памятка — **черновики**, не утверждены автором. Сначала согласовать формулировки и математику, затем сверстать.
5. Запускать `python3 qa/check_examples.py`; проводить отдельную визуальную проверку PDF на А4.

## Быстрый запрос Codex

> Прочитай AGENTS.md, контент и исходный SVG. Сделай математический и редакторский аудит только неподтверждённых блоков, предложи минимальные изменения. Не переписывай утверждённый блок 01. Затем помоги собрать печатную SVG/PDF-памятку строго в стиле оригинального SVG. Не заменяй SVG растровой картинкой. Перед публикацией проверь вычисления, выравнивание, отсутствие наложений и печать на А4.

## Структура

- `content/` — текст отдельно от графики; явно указаны статусы утверждения.
- `design/` — авторский SVG-образец и правила оформления.
- `qa/` — контрольный список и вычислительная проверка примеров.
- `publish/` — короткий текст к публикации.

**Важно:** неизвестно, включает ли текущий школьный набор уравнения вида `3x = 12`. В этих черновиках нет правила деления/умножения обеих частей. До публикации сверить по тетради/учебнику и не обещать универсальную применимость.
